# Billetera Digital: Pago y Movimientos

## Versiones

- Node.js 24
- Angular 21
- Bootstrap 5.3.3

## Estructura

```text
src/app/
├── app.ts
├── movimiento.ts
├── billetera/
│   ├── billetera.component.ts
│   └── billetera.component.html
└── nuevo-movimiento/
    ├── nuevo-movimiento.component.ts
    └── nuevo-movimiento.component.html
```

## Ejecución

```bash
npm install
npm start
```

http://localhost:4200/
